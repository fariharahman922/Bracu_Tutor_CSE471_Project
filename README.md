# **Bracu Tutor - CSE471 Project**

This repository contains the **Bracu Tutor** system, an academic project developed for **CSE471: System Analysis and Design**. The platform is an online tutor management system that facilitates **student-tutor interaction**, **booking**, and **feedback collection**.

---

## **Project Overview**

**Bracu Tutor** is designed to provide a seamless, intuitive online platform where **students** and **tutors** can register, interact, book sessions, and manage their academic activities efficiently. The system automates **booking**, **communication**, **payment**, and **feedback processes**, improving operational efficiency and academic outcomes.

---

## **Features**

- **User Authentication**: Sign Up, Login, Logout  
- **Profile Management**: Update or delete profile information  
- **Course, Department, and Tutor Lists**  
- **Search and Filter Tutors** by Department and Course  
- **Tutor Booking and Booking Management**  
- **Payment Integration** for Tutoring Sessions  
- **Tutor Ratings and Reviews**  
- **Real-time Chat Between Student and Tutor**  
- **Appointment Status Tracking** (Due, Done, Cancelled)  
- **Dashboard Overview** for Admin and Users  

---

## **Technologies Used**

- **Backend**: Python (Flask)  
- **Frontend**: HTML, CSS, JavaScript  
- **Database**: MySQL with PyMySQL ORM  
- **Deployment**: Render  

---

## **How to Run**

1. **Clone the repository**:
   
   git clone https://github.com/abu-ferdous-shawon/Cse471-project-final
   
2. **Navigate to the project folder**:
   
   cd bracu-tutor
   
3. **Install dependencies**:

   pip install -r requirements.txt
   
4. **Run the Flask application**:
   
   python app.py
   
5. **Access the system via browser**:
    http://127.0.0.1:5000/
